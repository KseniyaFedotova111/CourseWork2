# Приложение для интеграции с внешним сервисом

## Описание:

Приложение для интеграции с внешним сервисом - объединение данных, находящихся в различных источниках, и предоставление данных пользователям в унифицированном виде.

## Цель проекта:

Создать приложение для интеграции с внешним сервисом

## Установка:

Клонируйте репозиторий:

```
https://github.com/KseniyaFedotova111/CourseWork2.git
```

Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Пример работы с функциями:

1. Функция `load_vacancies` загружает вакансии из json-файла
2. Функция `filter_vacancies_by_salary` фильтрует вакансии по минимальной зарплате и валюте
3. Функция `filter_vacancies_by_keywords` фильтрует вакансии по ключевым словам
4. Функция `sort_vacancies` фильтрует вакансии по зарплате по убыванию
5. Функция `get_top_vacancies` возвращает топ n вакансий
6. Функция `print_vacancies` выводит вакансии в консоль
7. Функция `main` основная функция для взаимодействия с пользователем
8. Функция `connect_to_api` проверяет соединение с api HH
9. Функция `load_vacancies` загружает вакансии по ключевому слову
10. Функция ` __init__` инициализирует объект HH для работы с api HH
11. Функция `__load_vacancies` загружает вакансии из json-файла
12. Функция `__save_vacancies` сохраняет вакансии в json-файл
13. Функция `add_vacancy` добавляет вакансию в json-файл, если она не дублируется по url
14. Функция `get_vacancies` возвращает список всех вакансий из json-файла
15. Функция `delete_vacancy` удаляет вакансию из json-файла по url
16. Функция `validate_currency` валидирует валюту, возвращает rur, если валюта некорректная
17. Функция `format_salary` форматирует зарплату для вывода
18. Функция `validate_url` проверяет и возвращает корректный url
19. Функция `clean_string` очищает строку от лишних пробелов и символов
20. Функция `__str__` строковое представление вакансии
21. Функция `__lt__` сравнение вакансий по зарплате (меньше)
22. Функция `__gt__` сравнение вакансий по зарплате (больше)
23. Функция `to_dict` преобразует вакансию в словарь для json
24. Функция `from_dict` создает вакансию из словаря
25. Функция `get_salary` возвращает зарплату для сортировки

## Тестирование

Для тестирования функционала используется фреймворк pytest. Тесты находятся в директории tests и покрывают основные
функции проекта.

Для запуска тестов выполните команду:

```
pytest
```

## Описание тестов:

1. **Тестирование** `test_validate_currency`: тестирует валидацию валюты
2. **Тестирование** `test_format_salary`: тестирует форматирование зарплаты
3. **Тестирование** `test_validate_url`: тестирует валидацию url
4. **Тестирование** `test_clean_string`: тестирует очистку строк
5. **Тестирование** `test_vacancy_init`: тестирует инициализацию вакансии
6. **Тестирование** `test_vacancy_init_empty`: тестирует инициализацию с пустыми данными
7. **Тестирование** `test_vacancy_init_invalid_salary`: тестирует инициализацию с некорректной зарплатой
8. **Тестирование** `test_vacancy_from_dict`: тестирует создание вакансии из словаря
9. **Тестирование** `test_vacancy_to_dict`: тестирует преобразование вакансии в словарь
10. **Тестирование** `test_vacancy_get_salary`: тестирует метод get_salary
11. **Тестирование** `test_vacancy_slots`: тестирует использование __slots__
12. **Тестирование** `test_vacancy_comparison`: тестирует сравнение вакансий по зарплате
13. **Тестирование** `test_main`: тестирует основную функцию main
14. **Тестирование** `test_add_vacancy`: тестирует добавление вакансии в JSONSaver
15. **Тестирование** `test_get_vacancies_empty`: тестирует получение пустого списка вакансий
16. **Тестирование** `test_delete_vacancy`: тестирует удаление вакансии по url
17. **Тестирование** `test_add_vacancy_duplicate`: тестирует добавление дублирующейся вакансии
18. **Тестирование** `temp_vacancies_file`: создаёт временный json-файл с тестовыми вакансиями
19. **Тестирование** `test_load_vacancies`: тестирует загрузку вакансий из json-файла
20. **Тестирование** `test_load_vacancies_file_not_found`: тестирует загрузку вакансий при отсутствии файла
21. **Тестирование** `test_filter_vacancies_by_salary`: тестирует фильтрацию вакансий по минимальной зарплате
22. **Тестирование** `test_filter_vacancies_by_keywords`: тестирует фильтрацию вакансий по ключевым словам
23. **Тестирование** `test_sort_vacancies`: тестирует сортировку вакансий по зарплате
24. **Тестирование** `test_get_top_vacancies`: тестирует получение топ-n вакансий
25. **Тестирование** `test_main`: тестирует основную функцию main
26. **Тестирование** `test_connect_to_api_success`: тестирует успешное подключение к api HH
27. **Тестирование** `test_connect_to_api_failure`: тестирует ошибку подключения к api HH
28. **Тестирование** `test_load_vacancies_success`: тестирует успешную загрузку вакансий с HH
29. **Тестирование** `test_load_vacancies_empty`: тестирует загрузку пустого списка вакансий
30. **Тестирование** `test_load_vacancies_request_exception`: тестирует обработку исключения при загрузке вакансий
